# Kalaignar Tribute Series — Archival Workflow

## Source Layer

The `chronological/` directory is the source-of-record conversation archive.

It must remain unchanged.

## Processing Layer

The processed layer extracts:

- historical context
- project milestones
- decisions
- methodologies
- reusable practices

## Preservation Principles

### 1. Source First

Original transcripts and conversation records are preserved before interpretation.

### 2. Traceability

Every curated statement should be traceable to one or more chronological archive sections.

### 3. Separation

Raw conversations and derived summaries are maintained separately.

### 4. Reusability

The extracted workflow should help future Kalaignar archival projects follow a consistent process.
